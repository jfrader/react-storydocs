# Installation

Add the package and its peers:

```bash
pnpm add @acme/ui react react-dom
```

| Peer | Range |
| --- | --- |
| `react` | `^19.0.0` |
| `react-dom` | `^19.0.0` |

> Import `@acme/ui/tokens.css` once, at the root of the app.

Start with the [Button](#/components/button).
